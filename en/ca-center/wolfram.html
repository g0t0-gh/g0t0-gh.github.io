Wolfram's 1D Cellular Automata

Intoduction

Wolfram's 1D cellular automata have been created by Stephen Wolfram in 1983.[1] These automata can translate to a interger in 0~255 from this way below: 

The neighbours: 111 110 101 100 011 010 001 000
Next state:      1   0   1   1   0   0   0   0
10110000 in binary is 176 in decimal, so the interger of the rule is 176, and the rule is called Rule 176.

Symmetries

Flipping: 01101011 -> 11010110
The rule 

111 110 101 100 011 010 001 000
 1   0   1   1   0   0   0   0
will turn to 
111 011 101 001 110 010 100 000
 1   0   1   1   0   0   0   0
.
Black-white invertion: 01101011 -> 10010100
The rule 
111 110 101 100 011 010 001 000
 1   0   1   1   0   0   0   0
will turn to 
>000 001 010 011 100 101 110 111
 0   1   0   0   1   1   1   1
.

Definitions

Turing-Complete+ means Turing-Complete with finite population.
PRAM means parallel, random-access machine.
All the computing complexness are optimized.
